# Archipelago (archipelago.tools)

Agent memory for human brains: your agent's plans and decisions as a map you read, correct, share.

Each agent session is told where your projects stand when it opens, and leaves the map true when it ends: tasks, decisions and what waits on whom. You read it as a map in your browser, correct what is wrong, and share a view with a link. Every change is logged with whose word it rests on, and any of it can be undone. The core is unopinionated: its types, views and rules come in packs you shape to your work. Hosted in Canada; the server is MIT open source. Early, and used every day on its own development.

Install: https://app.archipelago.tools/connect/install
Source: https://github.com/AlexReiner98/archipelago

Not the multiworld randomizer of the same name, at archipelago.gg.
